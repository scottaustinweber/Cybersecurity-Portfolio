# Cybersecurity Portfolio

Hands-on lab work completed through the Google Cybersecurity Professional Certificate, documenting practical experience in access control, security investigation, and SIEM-based threat detection.

## Contents

**NIST CSF 2.0 Gap Assessment (Botium Toys)** Conducted a full gap assessment against the official NIST CSF 2.0 Organizational Profile Template, redoing the Google Cybersecurity Certificate's Botium Toys security audit exercise. Identified 12 distinct findings, assigned current/target maturity tiers with supporting rationale, and produced a prioritized recommendations memo and governance policy drafts adapted from SANS Institute templates.

**File Permissions & Access Control (Linux)**
Applied Linux command-line tools to audit and modify file and directory permissions for a simulated organization, enforcing least privilege access principles.

**SQL Filtering for Security Investigation**
Used SQL queries to filter login attempt data and employee records during a simulated security incident investigation, identifying suspicious after-hours activity and isolating machines requiring security updates by department.

**Access Control Automation (Python)**
Built a Python algorithm to automate IP address access control, parsing an allow list file and removing flagged users from restricted access.

**SIEM Investigation (Wazuh)**
Investigated a simulated security dataset using Wazuh's Discover module, isolating 384 failed root SSH login attempts through iterative query refinement, and re-verified the result before reporting it rather than relying on the first search return.
